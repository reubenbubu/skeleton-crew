## Decisions taken without the user

Recorded in the README ("Gates", "Review and merge", "Session recovery", "Conventions", "The `crew` CLI") and open to overrule:

- Only the final `down` removes images. The gate's opening `down` keeps them, because it runs right before `build`, which replaces them anyway.
- `crew env down` keeps its images, so a Dev's next `crew env up` is fast; the README now says so in the command table.
- `--rmi local`, not `--rmi all`, so images that `compose.yaml` pulls by name stay.
